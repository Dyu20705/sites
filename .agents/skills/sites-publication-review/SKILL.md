# Publication review

1. Inventory tracked files and classify: canonical English docs, necessary code/tests, immutable scientific evidence, historical-only process material, and disposable output.
2. Verify F1 and every pinned artifact hash **before** proposing deletion, rename, translation or EOL normalization. Hash-pinned Vietnamese original evidence is not ordinary translatable docs.
3. Use English canonical documentation; keep the root README short, navigable, accurate about *merged* capabilities and explicit about unresolved science.
4. Confirm no secrets, local absolute paths, reviewer exposure data, agent transcript, redundant output or unlicensed redistributed content is introduced.
5. Preserve historical negative results in Git/evidence; remove process noise from publication without rewriting history.
6. Review full diff and CI on final SHA; give a verifiable disposition (READY, CONDITIONAL or BLOCKED). Never bypass owner authorization or present a template as a passing gate.
