# SITES

**SITES (Scholar Intelligent Trend Evolution System)** investigates how concepts appear and change in scholarly literature through reproducible, inspectable evidence.

The current research scope is deliberately narrow: a bounded scholarly corpus, explicit temporal semantics, a deterministic descriptive signal, and record-level provenance. Counts of matching titles are **not** evidence of historical availability, scientific importance, semantic accuracy, emergence, or future growth.

The accepted Research Exit is **retrospective descriptive only**. Original historical-as-of E3 has **not passed**; independent scientific accuracy is **not measured**. Review the linked decisions and immutable experiment evidence before making stronger claims.
