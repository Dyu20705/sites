# SITES — Scholar Intelligent Trend Evolution System

[Tiếng Việt](docs/vietnamese/README.md)

SITES is intended to explore systems for evidence-driven understanding of scientific and technological evolution. Scientific papers are the initial research domain, not a permanent limitation.

A potential capability chain is:

```text
evidence acquisition → monitoring → mining → trend detection
→ forecasting → decision support / optimization
```

The repository is currently in a **research / definition / design-baseline stage**. There is no active executable implementation, packaged application, or test suite in the current tree. The capabilities above describe a long-term direction, not completed features.

Implementation architecture is intentionally not yet committed. Storage, data providers, data models, entity resolution, processing, deployment, and analytical methods remain open decisions requiring evidence, validation, and explicit decision gates before adoption.

Git history and closed issues preserve previous design explorations. Issues #36–#61 are historical design material, not the active dependency graph or implementation roadmap. Previous decisions are not binding and become part of the active baseline only if independently re-evaluated and explicitly adopted.
