# SITES — Scholar Intelligent Trend Evolution System

SITES hướng tới việc hiểu sự tiến hóa của khoa học và công nghệ dựa trên bằng chứng. Bài báo khoa học là miền nghiên cứu ban đầu, không phải giới hạn lâu dài.

Không gian năng lực dài hạn:

```text
evidence acquisition → monitoring → mining → trend detection
→ forecasting → recommendation / decision support → automation / optimization
```

Dự án đang ở **M0 — định nghĩa dự án**, chưa có implementation hay bộ kiểm thử thực thi trong cây repository hiện tại. Month 1 (17/09–17/10/2026) tập trung vào detection và descriptive trend intelligence; công nghệ triển khai chưa được chọn.

Bắt đầu từ [mục lục tài liệu tiếng Việt](docs/vietnamese/README.md) và [M1 contract đang chờ review](docs/vietnamese/baseline/M1.md). Thiết kế và code trong Git history, cùng các issue #36–#61 đã đóng, là tư liệu lịch sử; không phải kiến trúc hoặc roadmap hiện hành.
