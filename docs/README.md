# Documentation

[English canonical documentation](english/README.md) is the entry point for the SITES specification, research method, architectural contracts, and product documentation.

The public documentation language is English. Existing Vietnamese translations on historical branches remain historical material; neither translations nor dated progress notes are authoritative for new decisions. **Exception:** immutable F1 evidence may refer to original English and Vietnamese contract bytes. Such artifacts must remain verifiable, with their exact hashes preserved, until an independently tested evidence-packaging decision is accepted.

Review the [repository publication policy](english/governance/REPOSITORY_POLICY.md) before adding or removing files. Git history and issue discussions preserve process logs without promoting them to maintained technical specifications.
