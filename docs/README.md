## Translation policy

Translations must preserve **meaning**, not sentence structure.

Across language versions, the following must stay aligned:

- decision IDs and statuses;
- dates, milestones, gates, and Definition of Done;
- research questions and evaluation criteria;
- scope boundaries and non-goals;
- factual claims, citations, and stated evidence limitations;
- current-state claims.

Natural phrasing is preferred over literal translation. Technical terms may remain in English when that is clearer in context, but ordinary prose should read naturally in the target language.

A language set is not considered complete until the corresponding file exists and has been reviewed. Do not create empty files only to make the directory tree look symmetrical.

When translations disagree on technical meaning, resolve the underlying decision or source document first; do not silently choose one wording as authoritative.
