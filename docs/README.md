## Translation policy

Translations preserve meaning rather than sentence structure. The following must remain aligned across both languages:

- decision IDs and statuses;
- dates, milestones, gates, and the Definition of Done;
- research questions and evaluation criteria;
- scope boundaries and non-goals;
- factual claims, citations, and stated limits of the evidence;
- current-state claims.

Each document should read naturally in its own language. Technical terms may remain in English when that wording is clearer and more precise, but ordinary prose should not read like a literal translation.

A language set is complete only when every corresponding file exists and has been reviewed. If two translations differ in technical meaning, resolve the underlying decision or source text first rather than silently treating either wording as authoritative.
